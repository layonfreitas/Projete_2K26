# Alterações desta prévia

- Mantido o visual atual do CoffeeVision; não foi aplicado o redesign das imagens conceituais.
- No mapa, o painel "Cadastrar lavoura" não fica mais sobre a lavoura em telas grandes: ele ocupa uma lateral própria à direita.
- Ao recolher, essa lateral vira uma faixa estreita "Cadastro", liberando quase toda a largura do mapa.
- Em celular, o painel continua flutuante, mas recolhido vira um botão compacto no canto direito.
- O botão **Buscar** fica sempre na extremidade direita da barra de pesquisa.
- As páginas principais deixaram de usar uma largura máxima centralizada e agora aproveitam a largura disponível da tela.
- As regras, chamadas de API e fluxo de cadastro não foram alterados.

Para testar:

```bash
npm install
npm run dev
```
